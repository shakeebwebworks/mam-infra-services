# MAM Infra Services — Website Demo

A responsive, single-page real-estate website concept based on the Instagram profile screenshot supplied in the conversation.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

For a local development server, you can use the VS Code Live Server extension.

## Deploy to Vercel
1. Create a new GitHub repository and upload `index.html`, `styles.css`, and `script.js`.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Other**. Build command: leave blank. Output directory: `.`.
4. Deploy.

## Before sending to the client / publishing
- Confirm the official business name, logo, phone number, email, office address and social links.
- Replace the sample property names and descriptions with verified listings.
- Replace the illustrative stock photos with MAM's approved project photos.
- Connect the enquiry form to a real endpoint, CRM, email service or WhatsApp. It is currently a front-end demo only.
- Confirm all current prices, availability, approvals, amenities and project specifications with the client.

## Notes
- The property cards, project copy and imagery are illustrative, not verified live listings.
- Images and Google Fonts load from external services and require an internet connection.
- No framework or build step is required.
